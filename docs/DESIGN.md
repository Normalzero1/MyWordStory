# MyWordStory 설계

혼자 쓰는 안드로이드 영어 단어 학습 앱. 일상회화와 IT 비즈니스 표현이 중심이다.
아래 결정은 인터뷰(Q1~Q39)로 확정했다. 괄호 안은 근거가 된 질문 번호다.

## 제품

- 사용자는 본인 1명이다. (Q1)
- 새 단어는 하루 상한을 둔다(기본 30, 설정에서 조절). 복습이 밀리면 새 단어를 자동으로 줄인다. (Q4)

## 단어 내용

- 직접 추가한 단어를 먼저 쓰고, 모자란 만큼은 후보 목록에서 자동으로 채운다. 후보 목록은 NGSL-Spoken, BSL, TSL을 합치고 중복을 뺀 것이다(CC BY-SA 4.0). 다른 앱의 데이터는 쓰지 않는다. (Q3, Q16, Q20, Q23)
- 단어는 앱에서 입력하거나(줄바꿈으로 여러 개를 한 번에) 안드로이드 공유 메뉴로 넣는다. (Q15)
- 단어가 학습에 뽑힐 때 Claude API(Haiku 등급)가 서버에서 내용을 만든다. (Q2, Q13)
  - 표제어, IPA, 품사
  - 한국어 뜻: 최대 3개, 태그에 맞는 뜻을 먼저
  - 영영 정의 한 줄
  - 현지 사용 맥락: 격식 정도, 미국/영국 차이, 실제로 쓰이는 상황
  - 동의어와 뉘앙스 차이, 자주 같이 쓰는 표현(collocation)
  - 예문 2개(일상 1, 비즈니스 1)와 한국어 번역
  - 태그(일상 / IT 비즈니스), 출처(직접 추가 / AI 추천 / 단어집)
  - 반의어와 어원은 넣지 않는다. (Q9, Q12)
- 단어 하나가 카드 한 장이다. 구동사와 관용구도 같은 방식으로 넣는다. (Q11)
- 검수 없이 바로 학습한다. 틀린 내용은 카드에서 고치거나 다시 만든다. (Q14)
- 발음은 단어를 만들 때 Google Cloud TTS(WaveNet)로 한 번 생성해 서버에 저장한다. 기기는 내려받아 오프라인에서도 재생하고, 파일이 없으면 안드로이드 기본 TTS로 읽는다. 미국식 발음이 기본이다. (Q18, Q28)

## 학습

- 복습 알고리즘은 FSRS다(공개 구현 사용). 플래시카드는 4단계(다시/어려움/알맞음/쉬움)로 채점하고, 4지선다는 정답이면 '알맞음', 오답이면 '다시'로 기록한다. (Q8, Q10)
- 처음에 수준 테스트를 한다(빈도 구간별 '앎/모름', 약 5분). 모르는 단어가 30%를 넘는 구간부터 학습을 시작한다. 학습 중에는 '이미 앎', '필요 없음' 버튼으로 단어를 뺀다. (Q21, Q30)
- 하루 학습은 새 단어부터 한다(카드 보기 후 4지선다로 확인). 그다음 복습은 플래시카드로 하고 가끔 4지선다를 섞는다. (Q22)
- 알림은 하루 한 번이고 시간은 설정에서 정한다. 알림에 그날 복습 개수를 보여 준다. (Q17)
- 통계는 다섯 가지를 보여 주고, 태그별로 나눠 볼 수 있다. (Q27, Q31)
  - 일별 학습량
  - 기억률 추이
  - 앞으로 14일 복습 예정량
  - 누적 단어 수
  - 연속 학습일

## 기술 구조

- 앱은 Kotlin, Jetpack Compose, Room(로컬 DB)으로 만들고 오프라인을 우선한다. (Q6, Q7)
- 안드로이드 기기 여러 대를 동기화한다. 복습 기록(이벤트)을 올리고 받아서 FSRS로 카드 상태를 다시 계산하고, 단어 내용 수정은 마지막 수정을 따른다. (Q26, Q29)
- 서버는 Kotlin Ktor와 PostgreSQL을 docker compose로 묶는다. 개발은 로컬에서 하고, 운영은 GCP e2-micro에 고정 IP를 붙여 쓴다. IP 요금 월 약 $4는 감수하고 $5 예산 알림을 건다. (Q19, Q36, Q37)
- 인증은 고정 토큰 하나다. 주소는 `word.normalzero.co.kr`이고, A 레코드는 본인이 추가한다. HTTPS는 Caddy가 Let's Encrypt에서 받는다. (Q1, Q24, Q32)
- LLM과 TTS 키는 서버에만 둔다. (Q2)
- 백업은 매일 DB 덤프를 Google Cloud Storage에 올려 7일치를 보관한다. (Q25)

## 개발과 배포

- 저장소 하나에 `app/`(안드로이드)과 `server/`(Ktor)를 두고, GitHub Actions로 빌드와 테스트를 돌린다. (Q34)
- 앱은 서명된 APK를 GitHub Releases에 올려 직접 설치한다. 서버는 미리 만든 Docker 이미지를 스크립트 한 줄로 받아서 갱신한다. (Q35)
- 개발 순서 (Q33):
  1. 단어를 추가하면 서버가 LLM으로 내용을 만들고 앱에 카드로 보이는 데까지
  2. 학습: FSRS, 플래시카드, 4지선다, 수준 테스트, 이미 앎
  3. 단어집 넣기와 자동 채우기, 오프라인과 여러 기기 동기화
  4. 발음, 알림, 통계, 백업

## 가정과 나중에 확인할 것

- 기기는 안드로이드만 쓴다고 가정했다.
- 무료 범위와 요금은 검색 결과로 확인한 것이므로, 가입할 때 공식 페이지에서 다시 확인한다.
